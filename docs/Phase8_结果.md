# Phase 8 结果：探针→基因折叠敏感性

> 脚本：`PVL_08_probe_sens.R`（WSL `~/PVL/scripts/`）
> 方法：GSE26549 探针→基因折叠分别用 **max** 与 **mean** 两种方式，重算进展 DEG 并与基线（max）对比；外部验证用 GSE227919 严重度梯度 ρ 复核两种折叠下的稳定性。
> 输出：`results/PVL8_probe_sensitivity.csv`

---

## 1. 结果

| 指标 | 值 |
|---|---|
| DEG 数（max 折叠） | 101 |
| DEG 数（mean 折叠） | 102 |
| 两法 DEG 交集 | 100 |
| Jaccard 相似度 | **0.971** |
| logFC 两法 Spearman | **0.997** |
| 外部梯度 ρ（max 折叠） | 0.473 |
| 外部梯度 ρ（mean 折叠） | 0.470 |

---

## 2. 解读

- max 与 mean 折叠产生的 DEG 集合**近乎一致**（Jaccard 0.971），logFC 排序几乎完全相关（ρ=0.997）。
- 外部严重度梯度 ρ 在两种折叠下分别为 0.473 与 0.470，**无实质差异** → 探针折叠方法对结论无敏感性隐患。
- 结论稳健：无需在稿件中把探针折叠方法列为主要方法学顾虑；选用 max 折叠（与 Phase 2 一致）即可。
