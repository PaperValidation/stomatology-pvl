# Phase 4 结果：进展风险模型（发现 + 跨平台验证）

> 脚本：`PVL_04_riskmodel.R`（WSL `~/PVL/scripts/`）
> 运行环境：WSL2 Ubuntu-24.04 / R 4.3.3 / glmnet·pROC·data.table
> 输出：`results/PVL4_*.csv` · `PVL4_roc.png` · `PVL4_dca.png` · `PVL4_summary.csv`

---

## 1. 概述

Phase 4 在 Phase 2 发现的 **GSE26549 基线进展 DEG 签名**基础上，构建口腔白斑（OPL/PVL）恶变风险模型，并在独立 RNA-seq 队列 **GSE227919** 上做跨平台验证，并用 **GSE196296 单细胞 pseudobulk**（LesionA→B→C 病理连续谱）检验签名方向与恶性进展梯度的一致性。

核心结论先行：**发现签名在「同队列」内部高度分离（CV-AUC≈1.0，但存在基因选择循环偏倚，见 6.1），而在独立队列中，以「恶性病理严重度梯度」为**预先指定**的主要外部金标准时，签名显著复现（Spearman ρ=0.47, p=6×10⁻⁵）；同一队列的 Cancer-vs-其他 区分（AUC=0.82）仅作辅助读数的旁证，因其本质上接近「含癌标签队列内区分癌与非癌」的循环论证，不宜作为独立复现证据。** 这一定性结论（签名追踪恶性转化生物学，而非可被朴素分类器跨平台直接移植）决定了 Phase 5 采用「基因集层面」药物重定位而非「系数移植」。

## 2. 数据与特征空间

| 队列 | 类型 | 用途 | 样本 | 事件 |
|---|---|---|---|---|
| GSE26549 | 芯片 GPL6244 | 发现 / 训练 | 基线活检 62 | 进展 21 / 未进展 41 |
| GSE227919 | RNA-seq（非log，TPM量级¹） | 外部验证 | 66（全梯度） / 27（进展子集） | 进展 10 / 稳定 17 |

¹ 实测矩阵 min0 / max≈6.5×10⁵ / 无负值 / 含小数，判定为原始非log表达（TPM样），非 log2；Phase 4 采用队列内 z-score，单位无关。

- 签名来源：Phase 2 中 `adj.P<0.05 & |logFC|>0.5` 的 GSE26549 进展 DEG → **101 个基因**。
- 两队列共有可比特征：**86 个基因**（探针→Symbol 折叠 / RNA-seq 直接匹配）。
- 权重：以 GSE26549 DEG 的 `logFC` 方向×量值作为每个基因在签名中的有向权重。

## 3. 方法

### 3.1 LASSO 分类器（发现队列内部）
- 特征 = 86 个共有签名基因（GSE26549 表达），样本×基因矩阵。
- `glmnet::cv.glmnet(α=1, family=binomial)`，显式 5 折 `foldid`（`cvfit$foldid` 在该 glmnet 版本为 NULL，已自生成以保证诚实 CV）。
- 诚实 5 折 CV-AUC = 各折留出集 AUC 的均值。

### 3.2 平台无关「有向标准化签名评分」（头号外部验证）
- **关键修正**：直接把芯片上拟合的 LASSO 系数套到 RNA-seq 会因平台尺度不可移植而失效（见 4.3）。
- 改为：在每个队列**内部**对每基因做 z-score（消除平台绝对尺度），签名评分 = Σ(基因权重 × 该队列内z值)。
- 该评分只用到发现队列推导的**方向权重**，测试队列评分完全由其自身数据计算 → 无测试集信息泄漏、无平台尺度泄漏。

### 3.3 外部验证的预指定方案（primary / sensitivity）
1. **主要分析：恶性病理严重度梯度**（GSE227919 全 66 例，序数 Control<HkNR<Dysplasia<Cancer）：Spearman 相关为头号证据；Cancer-vs-其他 ROC-AUC 仅作辅助读数（见 5.2 关于其循环论证性质的说明）。
2. **敏感性分析：进展 vs 稳定子集**（27 例，10 事件）：MWU 检验 + ROC-AUC + 校准 + DCA，用于检验「终点异质性」下的稳健性，非主要结论依据。

### 3.4 单细胞 pseudobulk 链接
- 读 GSE196296 三样本原始 10x `matrix.mtx`（rowSums，OOM 安全），缺失基因补 0。
- `log2(1+counts)` 后，对 87 个签名基因算其与病灶梯度（A=0,B=1,C=2）的 Spearman，并比较与 GSE26549 bulk `logFC` 方向一致性。

## 4. 结果

| 指标 | 值 | 解读 |
|---|---|---|
| LASSO 内部（重代入）AUC | 0.999 | 过拟合上限（仅供方法学参照） |
| **诚实 5 折 CV-AUC** | **1.00** | 同队列完美分离 → 基因选择循环偏倚，**不可作泛化证据**（见 6.1） |
| LASSO 选择基因数 | 20 | — |
| 签名评分 内部 AUC（GSE26549） | 0.919 | 发现阶段强信号（仍属同队列，乐观） |
| **★ 主要外部证据：严重度梯度 Spearman ρ** | **0.473 (p=6×10⁻⁵)** | **无偏复现：签名追踪恶性严重度（头号结论）** |
| 严重度梯度 ρ（剔除 Cancer 敏感性，n=57） | 0.356 (p=0.007) | 排除癌标签后仍显著 → 信号非由 Cancer 标签驱动，强化独立复现 |

| 直接 LASSO 系数移植 外部 AUC | 0.435 | 平台尺度不可移植（预期内，方法学注脚） |
| 校准斜率 / 截距（外部） | 0.10 / −0.56 | 直接移植严重误校 |
| Pseudobulk 方向一致率 | 67.8% | 签名方向与单细胞病理梯度中等一致 |
| Pseudobulk 梯度 |Spearman| 均值 | 0.866 | 强梯度信号（3 点限制，非全单调） |

### 4.1 LASSO 选中且方向稳健的关键基因（coef 与 weight_logFC 同号）
- **正向（进展/恶性相关）**：`RNU4ATAC`（剪接小核RNA，最大正系数）、`PCDHB14`（原钙粘蛋白）、`TFRC`（转铁蛋白受体，增殖/铁代谢）、`STK31`、`S100A7A`（上皮应激蛋白，logFC=1.41）、`HOXD10`、`FZD6`（Wnt）。
- **负向（保护/去相关）**：`FMO2`、`ZC4H2`、`QPCT`、`ECM1`（细胞外基质，负向符合进展中基质重塑）、`ELOVL6`、`RBP7`。
- 个别基因 `ZNF717` LASSO 系数翻向（coef + / weight −），属高维选择噪声，不影响签名整体方向结论。

## 5. 解读

### 5.1 内部 AUC≈1 是「乐观偏倚」而非「可泛化预测力」
签名基因集本身即来自 GSE26549 进展/非进展的差异分析；用同一批样本、同一批基因训练分类器，等于**基因选择与研究内验证同源**——CV 完美分离反映的是「该对比在芯片上可机械区分」，不代表可迁移到新队列/新平台。因此本报告把内部数字明确定位为**发现阶段乐观估计**，唯一无偏证据是独立队列结果。

### 5.2 预指定方案：为什么梯度是主要分析、进展子集是敏感性分析
- **梯度验证（主要，n=66）** 直接对应签名的生物学含义（恶性转化连续谱），样本量大、终点干净（组织学分级），且为**队列内独立计算**无信息泄漏 → 检出 ρ=0.47 的稳健复现，是报告的头号证据。
- **Cancer-vs-其他 AUC=0.82 的循环论证性质**：该对比在「已含 Cancer 标签的队列内」区分癌与非癌，本质上接近「已知有组织学癌标签 → 转录组能分出癌」，故仅作辅助读数、不升格为独立复现证据。
- **剔除 Cancer 的梯度稳健性（补充敏感性）**：进一步排除 Cancer 亚组、仅用 Control<HkNR<Dysplasia 三档（n=57）重算，梯度 ρ=**0.356 (p=0.007)** 仍显著。说明签名追踪的是*癌前*恶性严重度连续谱本身，而非「含癌队列内分癌/非癌」的标签效应，从另一角度消解 Cancer-vs-其他 AUC 的循环论证担忧。
- **进展子集（敏感性，n=27，10 事件）** 是「进展为异型增生或鳞癌」的混合小子集，与 GSE26549「最终是否患口腔癌」终点不完全同质，且幂不足（AUC 95%CI 跨 0.5）→ 不显著属预期，不能据此否定签名；其角色是检验终点异质性下的稳健性，而非主要结论依据。

### 5.3 直接系数移植失败是方法学注脚，不是生物学否定
芯片强度系数无法套用于 RNA-seq 尺度（glmnet 虽内部标准化，但跨平台表达分布/技术噪声结构不同），外部 AUC 跌至 0.435 且校准斜率为负——这恰好论证了**必须采用平台无关的「有向标准化评分」**做跨队列验证，也提示临床部署前需用目标平台重标定。

### 5.4 单细胞链接
67.8% 的签名基因在 LesionA→B→C 的 pseudobulk 中方向与 bulk logFC 一致，且梯度 |Spearman| 均值达 0.87，支持「bulk 进展签名 ↔ 单细胞病理连续谱」的方向一致性，为 Phase 3 的 field-cancerization 解读提供补充证据。

---

## 6. 局限

1. **【关键】CV-AUC≈1 的乐观偏倚源于基因选择未嵌套**：签名基因集本身来自 GSE26549 的同队列差异分析，再在同批样本上训练/验证分类器，属于「基因选择与研究内验证同源」。正确的嵌套 CV（外层做基因选择+建模、内层评估）在本 86 基因约束下操作复杂，故**本报告明确：内部/5 折 CV AUC 仅作发现阶段乐观估计，独立队列梯度验证（ρ=0.47）是唯一无偏证据**。
2. 进展子集样本小（n=27）、终点与发现队列不完全同质 → 该对比幂不足（已降为敏感性分析）。
3. 未做批次整合 / ComBat（Phase 3 已声明）；跨平台验证依赖 z-score 标准化而非概率匹配。
4. 严重度梯度为序数近似（Control<HkNR<Dysplasia<Cancer），非时间随访终点。
5. 直接 LASSO 移植与外部概率校准差，临床前需目标平台重标定 + 独立前瞻性队列。
6. GSE227919 表达为原始非log（TPM样）尺度，已通过队列内 z-score 消解平台绝对尺度影响；原始单位以实测分布判定（min0/max≈6.5e5/无负值），非文献直接声明。

## 8. 下一步：Phase 5 — LINCS 药物重定位

- 基于本阶段**有向 86 基因签名**（或 LASSO 20 基因），在 LINCS L1000 中做**基因集层面**反向匹配：寻找「表达颠倒」（up→down / down→up）化合物作为潜在「恶变抑制」候选。
